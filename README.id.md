**🌐 Bahasa:** [English](README.md) · Bahasa Indonesia

Internet penuh dengan tools "gratis" yang minta kartu kredit di langkah kedua. **Daftar ini beda.** Setiap entri di sini benar-benar bisa kamu pakai gratis, hari ini juga, lengkap dengan label jujur biar kamu tahu persis apa yang kamu dapat.

🌏 *Dikurasi dengan cinta untuk para kreator di mana pun — dengan sedikit ekstra untuk komunitas dev Indonesia.* 🇮🇩

**Arti label:**

- 🔓 &nbsp;**Open source** — gratis selamanya; kodenya bisa kamu baca & modifikasi.
- 🆓 &nbsp;**Gratis** — proprietary tapi benar-benar gratis; nggak butuh paket berbayar buat dipakai penuh.
- 💎 &nbsp;**Free tier** — freemium, tapi paket gratisnya cukup mumpuni buat diandalkan.
- 🌐 &nbsp;**Tanpa install** — jalan langsung di browser.

Kami cuma masukin tool freemium (💎) kalau free tier-nya *beneran berguna sendiri* — bukan demo yang dilumpuhkan.
