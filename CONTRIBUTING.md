# Contributing to Awesome Free Tools

First off — **thank you!** 🎉 This list only stays great because people keep it honest and up to date. Whether you're adding a hidden gem, fixing a dead link, or flagging a tool that quietly went paid, you're helping thousands of people.

New to open source? **This is a perfect first contribution.** If you get stuck, open an issue and we'll walk you through it. No question is too basic here.

---

## ✅ What belongs on this list

A tool qualifies if it meets **all** of these:

1. **Genuinely usable for free.** Either open source (🔓), fully free (🆓), or freemium (💎) with a free tier that's actually useful on its own — not a 7-day trial or a crippled demo.
2. **Active and maintained.** No abandoned projects or dead websites.
3. **Broadly useful.** It helps people get real work done (productivity, design, dev, learning, security, media, etc.).
4. **Safe and reputable.** No malware, no shady data practices, no "free" tools that are really data-harvesting traps.

When in doubt, suggest it anyway — we'll discuss it together in the pull request.

## ✍️ How to add a tool

Each entry follows **exactly** this format:

```markdown
- [Tool Name](https://official-website.com) — One-line description of what it does. LABEL
```

**Rules:**

- Link to the **official homepage** (or the GitHub repo for open-source projects).
- Description is **one sentence**, starts with a capital letter, ends with a period.
- Keep it factual and useful — say *what it does and why it's good*, not "the best tool ever."
- End with the correct label emoji(s):

| Label | Use when… |
|-------|-----------|
| 🔓 | The tool is **open source**. |
| 🆓 | It's **proprietary but completely free** to use. |
| 💎 | It's **freemium** with a genuinely useful free tier. |
| 🌐 | It **runs in the browser** (add alongside another label). |

**Good example:**
```markdown
- [Excalidraw](https://excalidraw.com) — Hand-drawn-style whiteboard for diagrams and sketches. 🔓 🌐
```

**Avoid:**
```markdown
- excalidraw - best drawing app ever!!! (no link, no label, hype, no period)
```

### Placement

- Add your entry to the **most relevant category**.
- Keep entries within a category **alphabetical-ish but readable** — group open-source picks near the top of a category when it makes sense. Don't stress about perfect ordering; we'll tidy up in review.
- If your tool doesn't fit any category and you think it deserves a new one, propose the new category in your PR description.

## 🚀 Step-by-step (first time? start here)

1. **Fork** this repository (button at the top-right of the GitHub page).
2. **Edit `README.md`** directly on GitHub — click the ✏️ pencil icon, no need to install anything.
3. Add your entry in the right category using the format above.
4. Scroll down, write a short commit message like `Add Excalidraw to Design & Graphics`.
5. Click **Propose changes → Create pull request**.
6. Fill in the PR checklist. Done! 🎉

A maintainer will review it, suggest tweaks if needed, and merge. That's it — you're now a contributor.

## 🐛 Reporting problems

You don't have to add tools to help. You can also:

- **Report a dead link** or a tool that went paid → open a [problem report issue](../../issues/new/choose).
- **Suggest a tool** without making a PR → open a [tool suggestion issue](../../issues/new/choose) and someone will add it.

## 📜 Ground rules

- Be kind and respectful — see our [Code of Conduct](CODE_OF_CONDUCT.md).
- One tool per pull request when possible (easier to review and discuss).
- No affiliate links, no self-promotion spam. Built something yourself? You can suggest it, but it's judged by the same bar as everything else.
